==================================================
   HOW TO USE YOUR NEW SOFTWARE
==================================================

Follow these steps to get everything running:

STEP 1: THE FIRST TIME ONLY
----------------------------
If you just downloaded this, you need to "Build" it first.
- If you use WINDOWS: Double-click the file named "setup.bat"
- If you use MAC or LINUX: Run "setup.sh" in your terminal.

Wait until it says "SUCCESS!" and then you can close that window.


STEP 2: STARTING THE APP
-------------------------
Every time you want to use the software:
- If you use WINDOWS: Double-click the file named "start_windows.bat"
- If you use MAC or LINUX: Run "start_mac_linux.sh" in your terminal.


STEP 3: OPENING THE APP
------------------------
Once you see "Starting development server at http://127.0.0.1:8000/":
1. Open your web browser (Chrome, Safari, etc.)
2. Type "http://127.0.0.1:8000/" in the address bar and press Enter.


STEP 4: LOGGING IN
-------------------
To use the admin backend, go to: http://127.0.0.1:8000/admin/
Your login is:
- Username: admin
- Password: admin123


STEP 5: HOW TO UPDATE (IMPORTANT!)
----------------------------------
When you get a new version of this software:
1. DO NOT DELETE your old folder.
2. Find the folder named "data" in your old folder. This contains your business data.
3. Copy the "data" folder into the new software folder.
4. Run the "setup" file again (Step 1) to update the system.

Your companies and transactions will be safe!


That's it! Enjoy your software!
